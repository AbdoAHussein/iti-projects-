                                                      HTML


HTML (HyperText Markup Language) : is the standard language used to create and structure web pages. It defines the content and structure of a website, such as headings, paragraphs, images, links, forms, tables, and more.

HTML was created by "Tim Berners-Lee" in 1993 while working at CERN. He developed HTML as part of the technologies that became the foundation of the World Wide Web.
first version html1.2 , The most widely used version throughout the 2000's was HTML 4.01 , We are currently in HTML5 We have been using HTML5 since 2011.
